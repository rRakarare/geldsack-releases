# Geldsack – Downloads

Hier liegen nur die Installationsdateien und Updates von **Geldsack**, einer persönlichen
Finanzübersicht für Windows. Alle Daten bleiben auf deinem PC.

**Download und Anleitung:** https://geldsack.eggi.me

Die neueste Version findest du unter [Releases](https://github.com/rRakarare/geldsack-releases/releases/latest)
(`Geldsack-Setup.exe`). Installierte Versionen aktualisieren sich von selbst.
